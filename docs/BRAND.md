# Documentation theme

Shared visual language for all markdown in this repo. Copy the header/footer blocks from [README.md](../README.md) when adding new docs.

| Element | Usage |
|---------|--------|
| Badges | [shields.io](https://shields.io) — stack row under title |
| HTTP | `200` brightgreen · `400` red · `422` orange · `504` yellow |
| Formats | SVG `#7E57C2` · PNG `#4CAF50` · JPEG `#FF9800` |
| Mermaid | `themeVariables` — primary `#FF3670`, secondary `#009688` |
| Callouts | Blockquote + emoji: tip, warning, success |
