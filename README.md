# Mermaid Render API

Specification-first repository for a service that renders Mermaid syntax into images.

Start with:

- [CURSOR_SPEC.md](CURSOR_SPEC.md) for the implementation spec.

Local reference files such as `vendor/mermaid/` and `mermaid-*.tgz` are intentionally ignored by git. The final implementation should download or install a pinned Mermaid version during setup/build instead of committing the full Mermaid distribution.
